# プロジェクト計画・意思決定

## 基準日

展示日を `T` とし、確定日を入れた時点で相対日程を実日付へ置き換える。展示日が確定するまでは、本番調達や公開を前提とした変更を確定扱いにしない。

## マイルストーン

| 期限 | マイルストーン | 完了条件 |
|---|---|---|
| T-16週 | 企画・会場条件確定 | 展示日、場所、対象者、責任者、予算上限が承認済み |
| T-14週 | 学内事前相談 | 施設、ネットワーク、個人情報、広報の申請経路が確定 |
| T-12週 | 技術成立性判定 | 実地GPS、画面状態、回線切替、簡易描画を検証済み |
| T-10週 | MVP設計凍結 | Must要件、保存期間、描画方式、本番配置を承認済み |
| T-8週 | MVP E2E | QR参加、撮影、経路再構成、到着、再生、写真ストーリー、削除まで通る |
| T-6週 | 展示統合 | 本番映像、音響、運営画面、フォールバックを統合済み |
| T-4週 | 負荷・障害試験 | 最大負荷、通信断、再起動、削除試験に合格 |
| T-2週 | 現地総合リハーサル | 本番機材・担当者で公開判定基準に合格 |
| T-1週 | 変更凍結 | 緊急修正以外を停止し、復旧用ビルドを保管 |
| T | 公開 | 開場チェックリストと責任者判断を完了 |
| T+1週 | 振り返り・削除確認 | データ削除、事故確認、評価、撤収を完了 |

## 役割と責任

実名は確定後に記入する。一人が複数役を兼ねても、責任の所在は分けて記録する。

| 役割 | 主な責任 |
|---|---|
| 企画責任者 | 目的、スコープ、予算、公開可否の最終判断 |
| 制作責任者 | 進行、要件変更、成果物統合 |
| 技術責任者 | Web、Backend、描画、セキュリティ、リリース |
| 表現責任者 | 3D、映像、音響、到着演出、アクセシビリティ |
| 個人情報責任者 | 同意、保存、削除、二次利用、事故対応の承認 |
| 会場責任者 | 設営、安全、電源、導線、警備、撤収 |
| 当日運営責任者 | 開閉場、監視、障害判断、連絡網 |
| 受付担当 | 参加案内、代替体験、到着支援 |

## 公開前に必要な決定

| 決定 | 期限 | 承認者 | 未決時の扱い |
|---|---|---|---|
| 展示日・開場時間 | T-16週 | 企画責任者・会場 | 日程を確約しない |
| 最大同時参加人数 | T-12週 | 企画・技術 | 暫定50で負荷設計 |
| Unity / TouchDesigner | T-10週 | 技術・表現 | 比較試作の評価表で決定 |
| 本番サーバー・DB | T-10週 | 技術・大学情報担当 | 単一公開環境を暫定案とする |
| 保存期間・同意文 | T-10週 | 個人情報責任者 | リアルタイム参加を公開しない |
| 未成年者対応 | T-10週 | 企画・大学担当 | 対象外または保護者同意を案内 |
| 音響・照明連携 | T-8週 | 表現・会場 | 映像単体で成立させる |
| 実軌跡の二次利用 | T-10週 | 個人情報責任者 | 行わない |
| 写真の公開範囲 | T-10週 | 企画・個人情報 | MVPでは本人画面だけに表示 |
| 写真保存先・保持期間 | T-10週 | 技術・個人情報 | 非公開保存、停止後24時間以内を暫定案とする |
| キャンパス経路グラフ | T-10週 | 技術・会場 | 主要導線だけをMVP対象にする |

## 予算・調達項目

- サーバー、ドメイン、TLS、監視
- 非公開オブジェクトストレージ、画像転送、削除・容量監視
- プロジェクター、スクリーン、音響、照明、制御機材
- PC、バックアップ端末、UPS、ネットワーク回線
- HDMI・音声・電源・変換・予備ケーブル
- 3Dモデル、地図、フォント、音源、素材のライセンス
- サイン、QR掲示、養生、設営備品
- 搬入出、人件費、保険、予備費

金額、発注期限、所有者、代替品、キャンセル条件を調達表に記録する。

## 変更判断

- T-10週以降のMust要件変更は、影響分析と責任者承認を必要とする
- T-2週以降は、公開阻害または安全・プライバシー問題に限り変更する
- 変更ごとにロールバック方法と再試験範囲を定める
- 未決事項を暗黙の決定として実装しない。暫定値には期限と承認者を付ける
