## 機材候補と確認台帳

機材名は役割を検討するための候補であり、型番・数量・所有者・調達可否・予備機の確約ではない。描画方式はthree.js、描画クライアントはFrontendの`/display`に決定済み（Issue #12）。描画機からBackendへの外向きWSSの経路・認証と本番の利用許可は別途確認する。GPS、NFC、参加者の匿名IDを使った手動到着は構成に含めない。到着は展示ブースの署名・期限付きQRをBackendで検証する（Issue #23）。

| 用途・候補 | 現地で埋める情報・動作確認 |
|---|---|
| 描画PC（Mac mini M4またはGPU搭載ノートPCを候補） | 実機型番、台数、所有者、調達期限、設置位置、映像出力、GPU・メモリ、冷却、8時間稼働試験、代替端末 |
| 運営・受付端末（ノートPCを候補） | 台数、所有者、調達期限、配置、ダッシュボード、受付案内と到着キュー操作、代替端末。端末から匿名IDを指定して到着を成立させない |
| 投射・音響（プロジェクター、スクリーン、スピーカー等） | 各型番・台数・所有者・調達期限、代替品、投射距離・輝度・解像度・入力・音量上限・設置方法 |
| 回線・配線・電源（LAN、必要な変換・予備ケーブル、電源タップ、UPS・モバイル予備回線は必要性を判断） | 所有者・調達期限・代替品、接続口と必要帯域、回路容量、コンセント位置、接地、タップ許容負荷、予備ACアダプター、養生方法 |
| 任意の外部制御機材（Raspberry Pi、LED・照明等は採否未決） | 導入の要否、型番・数量・所有者・調達期限、設置・電源、安全、障害時の切離し方法。採用しなくても映像単体で成立させる |

各行について実物ごとに型番、数量、所有者・貸出元、手配担当、調達期限、設置場所、代替品の確保状況、確認者、確認日、結果と証跡を機材台帳へ記録する。現時点ではこれらの個別情報と予備機の確保は未確認。貸出・購入・代替は予算上限5,000円（課金責任者Mino829）と会場承認を確認してから確定し、候補機材を所有済みと扱わない。台帳の保管先と更新担当も会場責任者・当日運営責任者の決定時に記録する。

## 当日運営と停止条件

会場・当日運営・受付・事故連絡の実担当と連絡網、開場/閉場/撤収の担当・期限は未決。企画責任者はMino829だが、他の役を兼任したと見なさない。役割と連絡先を確定して運営者へ手順を引き継ぎ、本番機材で運営者だけの起動、入口/到着QR案内、表示・受付停止、障害/事故連絡、合成展示への切替、再開判断、閉場時の停止・削除確認、撤収をリハーサルする。各手順の実施者・日時・合否を記録する。合成展示は参加者の実データを使わず、GPSなしで成立させる。

運営者用の確認順（担当確定と実機リハーサル前の案であり、合格済み手順ではない）:

1. **開場前**: 会場許可と安全・配線、連絡先、機材台帳の実物、回線、描画機と投射・音量を確認する。合成データで入口QR→撮影/地点選択→到着QR→簡易表示と削除を通し、受付停止・バックアップ映像への切替も担当者自身で試す。公開判定の記録と当日責任者の判断を確認してから受付を開始する。
2. **開場中**: 受付列、投射/描画接続、回線、写真メタデータ登録と端末画像保存の案内、サーバーの期限削除ジョブと旧クラウド写真の清掃状態、非常導線を確認する。端末を開かない間の画像消去を運営側で保証しない。異常時は新規受付を停止し、実データを再表示しない合成映像または承認済みの保存映像へ切り替え、障害時刻・影響と連絡先を記録する。復旧だけで受付を自動再開しない。
3. **閉場・撤収**: 受付停止、描画/投射の停止、期限削除ジョブの稼働・失敗件数と未削除データの扱いを確認する。電源・配線・掲示を会場の撤収条件に従って片付け、事故/未解決事項と引継ぎ先を記録する。削除予定時刻の到来を削除完了と見なさない。

各段階の操作画面・権限、担当と代行者、連絡先、実施時刻、結果、証跡の保管先を現地で埋め、当日運営者が説明なしで実施できるまで本番機材でリハーサルする。受付停止や合成展示切替を実行できない構成は公開可能と判定しない。

教室使用や安全・電源の承認がない場合は設営・通電・公開しない。必要な学内許可、責任者・連絡網、回線、実機試験または[公開判定](test-plan.md#公開判定)の条件が未達なら実データ受付を開始しない。合成データ展示も会場の設置・安全承認と操作可能な担当を要し、それらが欠ければ公開を見送る。事故、漏えい疑い、危険な配線/過負荷時は受付と該当機材の使用を停止し、会場・技術・個人情報の関係責任者へ連絡して指示を受ける。復旧・再開は原因と再確認結果を記録し、責任者が判断する。公開やリハーサルが完了したという記録は現時点でない。
