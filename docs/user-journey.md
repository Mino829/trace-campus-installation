# 参加者ジャーニー・画面要件

本資料は2026-10-26の決定（Issue #23）に基づき、GPS不使用・写真地点自己申告の仕様へ全面改訂した。リアルタイム位置・`LivePresenceSession`・`on_site`・集合表現への参加・色・記号による照合表示の記述は廃止した。Web Pushは30分ごとの撮影リマインダーのみである。

## 基本方針

- カメラ権限のブラウザダイアログを出す前に、作品側の説明と同意を完了する。位置情報の権限は要求しない
- カメラ権限の説明を権限要求前に示す。カメラの許可が参加の条件である
- 参加中か、完了したか、期限切れかを常に明示する
- 「写真ストーリーの保存」と「保存済みデータの削除」を別の操作として説明する
- セッションIDをスクリーンや運営画面へそのまま表示しない
- カメラを許可しない人は参加せず、展示を観覧できる。代替参加は用意しない
- 対象はiOS 16.4以上とAndroid版Chrome 111以上とする。対象外の版とアプリ内ブラウザでは参加を始めず、Safari・Chromeで開くよう案内する。アプリ内ブラウザの記録はSafari・Chromeと共有されず、途中で移ると参加を続けられないため
- iPhoneではホーム画面に追加したWeb Appから始めるよう案内する。通知はホーム画面のWeb Appにしか届かないため。Safariのタブのままでも参加できる
- 同じブラウザなら、再読込・別タブ・通知から開き直しても同じ参加を続けられる。同じ人がもう一度参加することは止めない
- 写真を思い出の主役とし、公開スクリーンには原写真を表示しない

## 正常系ジャーニー

| 段階 | 参加者の操作・認識 | システム処理 | 成功条件 |
|---|---|---|---|
| 1. 発見 | 入口の案内とQRを読む | 参加URLを開く | 目的、所要時間、通信・電池、任意参加が分かる |
| 2. 説明 | 写真・地点の選択項目、表示、保存、削除を読む。位置情報の取得はないと分かる | 有効な同意文を取得する | カメラの権限要求前である |
| 3. 同意 | 同意して開始する | 匿名の`MemorySession`を単独で発行する | 同意版と記録言語を記録する。LivePresenceSessionは発行しない |
| 4. 権限 | ブラウザのカメラ利用を許可する | カメラを準備する | カメラを許可した場合だけ撮影へ進む |
| 5. 撮影 | 残したい瞬間を撮り、写真ごとに3Dマップで地点（チェックポイント）を選ぶ | PhotoMomentを`checkpointId`とともに保存する。座標・ノードID・グラフ版は送らない | 写真の送信状態と地点選択の完了が分かる |
| 6. 到着 | 展示ブースの列に並び、自分の番でプロジェクター映像の到着QRをWeb Appで読む | 到着証明を検証して`arrived`へ移し、到着キューへ一度だけ登録する。ArrivalEventを作り撮影通知を停止する | 通知が停止し、再読込しても状態が戻る |
| 7. 再生 | 展示ブースで自分の写真メモリーの再生を見る | 撮影順に地点を最短経路でつなぎ、最後の写真からShibaLabまで同じ線で、全体10〜20秒・区間長に比例配分して再生する。写真地点で少し停止する | 他者のID、生位置、原写真を表示しない |
| 8. 完了 | 写真ストーリーを見返し、端末へ保存する。完了状態と自動削除予定日時を確認する | 完了状態を表示する。順位・待ち時間・集合表現への参加は出さない | 参加トークンを持つ本人だけが閲覧できる |

## 画面一覧

### 入口・概要

- 一文コンセプト
- 推奨所要時間
- カメラ利用、写真枚数・容量、公開スクリーンに原写真を出さないこと
- 位置情報を取得しないこと。写真の地点は参加者が3Dマップで選ぶこと
- 「参加する」と、カメラの許可が参加の条件であること
- 対象外の版では「参加する」の代わりに「この端末では参加できません」を出す
- アプリ内ブラウザでは「参加する」を押せなくし、Safari・Chromeで開くよう案内する
- iPhoneのSafariのタブでは、ホーム画面に追加して始める案内と「通知なしでこのまま参加する」を出す。このまま参加する場合は「プライベートブラウズでは記録が正常に保存されません。通常のタブで開いてください」も出す
- 日本語・英語切替。ただし同意文の現行版は ja のみ（`2026-memory-photo-no-gps-draft-1`）で、英語版は大学審査後とする（2026-10-26決定、#23）

### 説明・同意

- 取得する情報、取得しない情報（位置情報は取得しない）
- 写真を本人用ストーリーへ使い、一般公開しないこと
- 写真ごとに3Dマップ上で地点を選ぶ必要があること
- 展示上の抽象化方法
- 保存期間、停止、即時削除、問い合わせ先
- 同意チェックと開始ボタン

### 参加中

- 状態: 送信待ち、保存済み、再送待ち、失敗
- 撮影ボタン、撮影枚数、残り上限
- 写真ごとの3Dマップ上の地点選択画面。選択が必須であること
- 写真ごとの送信中、保存済み、再送待ち、失敗状態
- 他人の顔、名札、個人情報、撮影禁止場所を写さない案内
- ShibaLab（展示場）への簡易案内。精密ナビゲーションは行わない
- 30分間隔の撮影リマインダー設定。参加の標準として案内し、通知を許可しなくても体験を継続できる
- 撮った写真を1枚ずつ本人端末へ保存する

### 撮影確認

- 撮影写真のプレビュー
- 3Dマップ上の地点選択。チェックポイントを必ず選ぶ（選択しないと保存できない）
- 撮り直す、思い出へ追加する
- 写真は公開スクリーンへ出ないこと
- 送信・保存の進行とキャンセル

### 到着後

- 「あなたの演出を準備中」
- 再生をスキップして終了
- 撮影通知が停止したことが分かる表示

### 完了

- 完了状態と自動削除予定日時
- 写真ストーリーを見返す。ストーリーをまとめた画像と写真1枚ずつを本人端末へ保存する。保存しても自動削除日時は延びない
- 写真単位で削除する
- セッション全体（写真・経路・地点・Push購読）を削除する
- 順位・待ち時間・集合表現への参加に関する表示は行わない
- 問い合わせ先

## 例外系

| 状況 | 参加者への案内 | システム処理 |
|---|---|---|
| カメラ権限拒否 | 参加できないことと設定変更方法を案内 | 参加へ進めない。位置権限は関係しない |
| 地点を選択できない | 3Dマップの読み込み・選択肢が復帰した時点で選択を促す | 対象の写真は「場所不明の記憶」として保存する |
| 写真送信失敗 | 再送、端末保存、写真削除を選べる | 12枚・30MB上限で端末へ一時保持する |
| 写真上限到達 | 既存写真の確認・削除を案内 | 新規撮影を停止し既存データを保護する |
| 通信断 | 写真は復旧後の再送待ちになることを表示 | 写真＋`checkpointId`だけを上限内で一時保持する |
| 通知が届かない | OS・ブラウザにより遅延することと画面内タイマーを案内 | 写真体験と公開可否には影響させない |
| 通知をオンにできない | 「プライベートブラウズでは記録が正常に保存されません。通常のタブで開いてください」と案内 | 通知なしで参加を続けられる |
| 対象外の端末・アプリ内ブラウザ | 参加できないこと、またはSafari・Chromeで開くことを案内 | 参加を始めない |
| 開き直し | 同じブラウザなら、再読込・別タブ・通知・タブを閉じた後でも同じ参加を続ける | `localStorage`の有効トークンで、位置そのものを返さず状態を返す |
| 参加を続けられない | 「この画面には、前の参加の記録がありません。参加を始めたブラウザか、ホーム画面のアプリで開いてください。開けないときは、もう一度「参加する」から参加できます。」と案内 | 別のブラウザ・端末、iPhoneのSafariとホーム画面Web Appの移動、プライベートブラウズの終了で起きる。前の参加は`delete_after`で自動削除する |
| 到着QRが無効 | 展示ブースに投影中のQRを読み直すよう案内 | 到着を登録しない |
| 軌跡が短い（写真0枚・1枚） | 簡易表示（スポット名や写真の有無の案内）として再生する | 失敗扱いにせず安全に完了する |
| キュー滞留 | 準備中であることとスキップを表示する | タイムアウト後に自動skip可能 |
| 描画停止 | 再生不能と案内する | フォールバックへ切替しキューを整理する |
| 削除実行 | 取り消せないことを確認する | 写真、経路、写真地点、Push購読を削除しトークンを無効化する |
| 経路を確定できない | 「道の記憶が曖昧です」と自然に表現する | 直線を実歩行として保存せず未確定区間とする |

## 自分の演出の識別

参加者は展示ブースの列で自分の番に到着QRを読むため、直後の再生を自分の演出と分かる。スマホと展示に同じ色・記号を表示して照合する仕組みは使わない（Mino829/TRACE_F#10、2026-10-26決定#23で廃止）。

- 氏名、連番、セッションID、歩いた場所の名称は表示しない
- 参加者が「自分だ」と公に示す操作を必須にしない

## アクセシビリティ

- 主要操作をキーボードと画面読み上げで利用できる
- 200%拡大でも開始・停止・削除が隠れない
- 状態を色だけで伝えない
- 強い点滅を避け、必要な場合は会場入口に警告と代替導線を示す
- 同意内容は現行版 `2026-memory-photo-no-gps-draft-1` を日本語で提供する。英語版は大学の審査を経た後に追加する（2026-10-26決定、#23）
