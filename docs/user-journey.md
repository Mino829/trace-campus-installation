# 参加者ジャーニー・画面要件

## 基本方針

- 位置権限のブラウザダイアログを出す前に、作品側の説明と同意を完了する
- 追跡中か、更新が止まっているか、終了したかを常に明示する
- 「追跡停止」と「保存済みデータの削除」を別の操作として説明する
- セッションIDをスクリーンや運営画面へそのまま表示しない
- 位置情報を提供しない観覧・代替参加も可能にする

## 正常系ジャーニー

| 段階 | 参加者の操作・認識 | システム処理 | 成功条件 |
|---|---|---|---|
| 1. 発見 | 入口の案内とQRを読む | 参加URLを開く | 目的、所要時間、通信・電池、任意参加が分かる |
| 2. 説明 | 取得項目、表示、保存、停止、削除を読む | 有効な同意文を取得する | 権限要求前である |
| 3. 同意 | 同意して開始を押す | 匿名セッションを発行する | 同意版と言語を記録する |
| 4. 権限 | ブラウザの位置利用を許可する | `watchPosition`を開始する | 拒否時は代替案内へ進む |
| 5. 歩行 | 追跡状態を確認しながら歩く | 検証済み位置を保存・配信する | 最終更新時刻が見える |
| 6. 到着 | 展示場の到着QRを読む | 到着証明を検証し追跡を停止する | 到着後の点を保存しない |
| 7. 待機 | 色・記号と予想順を確認する | 到着キューへ一度だけ登録する | 再読込しても状態が戻る |
| 8. 再生 | スマホと同じ色・記号の演出を見る | 10〜20秒で軌跡を再生する | 他者のIDや生位置を表示しない |
| 9. 完了 | 保存期限と削除ボタンを確認する | 集合表現へ抽象化して終了する | 追跡が停止済みと分かる |

## 画面一覧

### 入口・概要

- 一文コンセプト
- 推奨所要時間
- 位置情報の利用と電池・通信への注意
- 「参加する」「位置情報なしで楽しむ」
- 日本語・英語切替

### 説明・同意

- 取得する情報、取得しない情報
- 画面ロックやアプリ切替で位置更新が止まる可能性
- 展示上の抽象化方法
- 保存期間、停止、即時削除、問い合わせ先
- 同意チェックと開始ボタン

### 追跡中

- 状態: 取得中、精度低下、送信待ち、更新停止
- 最終更新からの経過時間
- 到着場所への簡易案内。ただし精密ナビゲーションは行わない
- 追跡停止、データ削除
- 画面を表示したままにする必要がある場合の案内

### 到着待ち

- 非識別の色・記号
- 「あなたの演出を準備中」
- 予想待ち時間または順番
- 再生をスキップして終了
- データ削除

### 完了

- 追跡停止済みであること
- 演出結果が集合表現へどう加わったか
- 自動削除予定日時
- 今すぐ削除
- 問い合わせ先

## 例外系

| 状況 | 参加者への案内 | システム処理 |
|---|---|---|
| 位置権限拒否 | 設定変更方法とQRチェックポイント参加を案内 | 生位置を取得・保存しない |
| 位置が取得できない | 屋外へ移動、画面表示、再試行を案内 | セッションを維持し無効点は保存しない |
| 30秒以上更新なし | 「現在、位置を更新できていません」と表示 | 最終有効位置を30秒保持した後に展示から自然に消す |
| 通信断 | 未送信件数と再送予定を表示 | 上限内で端末へ一時保持する |
| 端末再読込 | 同じ端末なら状態復元を試みる | 有効トークンで位置そのものを返さず状態を返す |
| 複数タブ | 既存セッションへ誘導する | 二重watch・二重到着を防ぐ |
| 到着QRが無効 | 正しい掲示または受付へ案内 | 到着を登録しない |
| 軌跡が短い | 短い光・生成表現として再生する | 最低点数未満でも安全に完了する |
| キュー滞留 | 待ち時間とスキップを表示する | タイムアウト後に自動skip可能 |
| 描画停止 | 再生不能と追跡停止済みを案内する | フォールバックへ切替しキューを整理する |
| 削除実行 | 取り消せないことを確認する | 関連データを削除しトークンを無効化する |

## 自分の演出の識別

参加者ごとに、十分な組み合わせ数を持つ色と記号をランダムに割り当てる。スマホの到着待ち画面と再生直前の展示に同じ組み合わせを表示する。

- 氏名、連番、セッションID、歩いた場所の名称は表示しない
- 色だけに依存せず、形・記号・動きも併用する
- 混雑時に同じ組み合わせが同時表示されないよう割当を管理する
- 参加者が「自分だ」と公に示す操作を必須にしない

## アクセシビリティ

- 主要操作をキーボードと画面読み上げで利用できる
- 200%拡大でも開始・停止・削除が隠れない
- 状態を色だけで伝えない
- 強い点滅を避け、必要な場合は会場入口に警告と代替導線を示す
- 日本語・英語で同じ同意内容を提供する
