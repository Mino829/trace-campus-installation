# 参加者ジャーニー・画面要件

## 基本方針

- 位置権限のブラウザダイアログを出す前に、作品側の説明と同意を完了する
- カメラ権限と位置権限を別々に説明し、両方の許可が参加の条件であることを権限要求前に示す
- 追跡中か、更新が止まっているか、終了したかを常に明示する
- 「追跡停止」と「保存済みデータの削除」を別の操作として説明する
- セッションIDをスクリーンや運営画面へそのまま表示しない
- カメラや位置情報を許可しない人は参加せず、展示を観覧できる。代替参加は用意しない
- 写真を思い出の主役とし、公開スクリーンには原写真を表示しない

## 正常系ジャーニー

| 段階 | 参加者の操作・認識 | システム処理 | 成功条件 |
|---|---|---|---|
| 1. 発見 | 入口の案内とQRを読む | 参加URLを開く | 目的、所要時間、通信・電池、任意参加が分かる |
| 2. 説明 | 写真・位置の取得項目、表示、保存、停止、削除を読む | 有効な同意文を取得する | カメラ・位置の権限要求前である |
| 3. 同意 | 使いたい写真体験・リアルタイム展示を選んで開始する | 別々の匿名セッションと短期連携を発行する | 各同意版と言語を記録する |
| 4. 権限 | ブラウザのカメラ・位置利用を許可する | カメラを準備し`watchPosition`を開始する | 両方を許可した場合だけ撮影・歩行へ進む |
| 5. 撮影・歩行 | 残したい瞬間を撮りながら歩く | PhotoMomentと撮影時GPSを保存し、量子化した短期ピンを表示する | 写真の送信状態と3D Mapへの反映が分かる |
| 6. 到着 | 展示ブースの列に並び、自分の番でプロジェクター映像の到着QRをWeb Appで読む | 到着証明を検証して`arrived`へ移し、到着キューへ一度だけ登録する | 通知が終了し、リアルタイム停止か会場内継続を選べる。再読込しても状態が戻る |
| 7. 再生 | 展示ブースで自分の軌跡の演出を見る | 写真間の再構成経路を10〜20秒で再生する | 他者のID、生位置、原写真を表示しない |
| 8. 振り返り | 写真と写真間の経路を時系列に見る | 本人用写真ストーリーを生成する | 参加トークンを持つ本人だけが閲覧できる |
| 9. 完了 | 端末保存、保存期限、会場内継続、削除を確認する | 集合表現へ抽象化する | 写真とリアルタイムの各状態が分かる |

## 画面一覧

### 入口・概要

- 一文コンセプト
- 推奨所要時間
- 位置情報の利用と電池・通信への注意
- カメラ利用、写真枚数・容量、公開スクリーンに原写真を出さないこと
- 「参加する」と、カメラと位置情報の許可が参加の条件であること
- 日本語・英語切替

### 説明・同意

- 取得する情報、取得しない情報
- 写真を本人用ストーリーへ使い、一般公開しないこと
- 画面ロックやアプリ切替で位置更新が止まる可能性
- 展示上の抽象化方法
- 保存期間、停止、即時削除、問い合わせ先
- 同意チェックと開始ボタン

### 追跡中

- 状態: 取得中、精度低下、送信待ち、更新停止
- 最終更新からの経過時間
- 到着場所への簡易案内。ただし精密ナビゲーションは行わない
- 追跡停止、データ削除
- 画面を表示したままにする必要がある場合の案内
- 撮影ボタン、撮影枚数、残り上限
- 写真ごとの送信中、保存済み、再送待ち、失敗状態
- 他人の顔、名札、個人情報、撮影禁止場所を写さない案内
- 任意の15分・30分リマインダー設定。通知拒否でも体験を継続できる
- 写真ピンは位置をぼかし、短時間で消え、写真自体は出ないこと

### 撮影確認

- 撮影写真のプレビュー
- 撮り直す、思い出へ追加する
- 撮影位置の取得状態と不確実さ
- 写真は公開スクリーンへ出ないこと
- 送信・保存の進行とキャンセル

### 到着後

- 「あなたの演出を準備中」
- 再生をスキップして終了
- データ削除
- リアルタイム位置を停止する、または説明を読んで会場内展示へ進む
- 会場内表示が点・エリア・操作時のどれかを明示する

### 完了・会場内

- リアルタイムが停止済みか、`on_site`で継続中か
- 演出結果が集合表現へどう加わったか
- 自動削除予定日時
- 写真ストーリーを見返す、本人端末へ保存する
- 写真単位で削除する
- 写真の思い出だけ、リアルタイム参加だけ、両方を削除
- 問い合わせ先

## 例外系

| 状況 | 参加者への案内 | システム処理 |
|---|---|---|
| 位置権限拒否 | 参加できないことと設定変更方法を案内 | 生位置を取得・保存せず、参加へ進めない |
| カメラ権限拒否 | 参加できないことと設定変更方法を案内 | 参加へ進めない |
| 撮影位置を取得できない | 写真は残るが場所不明になることを表示 | 通常GPSで補完せず経路外の記憶として保存する |
| 写真送信失敗 | 再送、端末保存、写真削除を選べる | 12枚・30MB上限で端末へ一時保持する |
| 写真上限到達 | 既存写真の確認・削除を案内 | 新規撮影を停止し既存データを保護する |
| 位置が取得できない | 屋外へ移動、画面表示、再試行を案内 | セッションを維持し無効点は保存しない |
| 30秒以上更新なし | 「現在、位置を更新できていません」と表示 | 最終有効位置を30秒保持した後に展示から自然に消す |
| 通信断 | 通常位置は復旧後の最新値だけ送ること、写真は再送待ちになることを表示 | 通常GPSは保持せず、写真＋撮影時GPSだけ上限内で一時保持する |
| 通知が届かない | OS・ブラウザにより遅延することと画面内タイマーを案内 | 写真体験と公開可否には影響させない |
| 会場内GPSが不安定 | エリア表示または操作時表示へ変わることを案内 | 点表示を停止し安全な粒度へ切り替える |
| 端末再読込 | 同じ端末なら状態復元を試みる | 有効トークンで位置そのものを返さず状態を返す |
| 複数タブ | 既存セッションへ誘導する | 二重watch・二重到着を防ぐ |
| 到着QRが無効 | 展示ブースに投影中のQRを読み直すよう案内 | 到着を登録しない |
| 軌跡が短い | 短い光・生成表現として再生する | 最低点数未満でも安全に完了する |
| キュー滞留 | 準備中であることとスキップを表示する | タイムアウト後に自動skip可能 |
| 描画停止 | 再生不能と追跡停止済みを案内する | フォールバックへ切替しキューを整理する |
| 削除実行 | 取り消せないことを確認する | 関連データを削除しトークンを無効化する |
| 経路を確定できない | 「道の記憶が曖昧です」と自然に表現する | 直線を実歩行として保存せず低信頼区間にする |

## 自分の演出の識別

参加者は展示ブースの列で自分の番に到着QRを読むため、直後の再生を自分の演出と分かる。スマホと展示に同じ色・記号を表示して照合する仕組みは使わない（Mino829/TRACE_F#10）。

- 氏名、連番、セッションID、歩いた場所の名称は表示しない
- 参加者が「自分だ」と公に示す操作を必須にしない

## アクセシビリティ

- 主要操作をキーボードと画面読み上げで利用できる
- 200%拡大でも開始・停止・削除が隠れない
- 状態を色だけで伝えない
- 強い点滅を避け、必要な場合は会場入口に警告と代替導線を示す
- 日本語・英語で同じ同意内容を提供する
