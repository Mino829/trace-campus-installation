# 作品コンセプト（完成版）

更新日: 2026-11-06

## 一文で表すと

「写真に残した瞬間と、そのあいだを歩いた時間が、すでに展示だった。」

TRACEは、参加者が写真とともに選んだ場所を、キャンパスの光の経路として振り返る作品である。写真は本人の端末に残り、展示には画像ではなく地点間の経路が現れる。「歩いた時間」は作品の主題であり、GPSで連続計測した実歩行履歴を意味しない。

## 体験

1. 同じ展示環境の参加者ページ`/log`を開く
2. Backendが配信する参加説明を読み、任意でMemory参加に同意する。サーバーでの作成成功を確認して開始する
3. 学園祭を楽しみながら写真を撮る。写真の確認後、建物・階・チェックポイントから場所を自分で選ぶ
4. 写真はEXIFを引き継がないJPEGとして端末内へ保存される。到着前の地点・時刻・写真照合IDだけがGoへ送られる
5. 写真一覧の「作品を見る」から、到着前でも写真・振り返り3D・一枚にまとまった作品を見て保存できる。ホームへ戻れば撮影を続けられる
6. 会場では展示中の有効なQRを読み、初回到着を登録する。待機中・再生中はその状態へ戻る
7. 単一の主描画機が待ち列順に、本人の選んだ地点を結ぶ光の経路を再生する。本人の写真は投影しない
8. 再生完了後も参加が有効なら、新しいQRを自分で読み直すことで同じ写真・参加のまま再視聴を申し込める
9. 写真・作品を持ち帰る、記録を残して参加を終了する、削除する、を選ぶ

到着登録と本人端末での作品鑑賞は別操作である。「作品を見る」はカメラ、到着登録、再予約、到着状態の照会、metadata送信待ちを始めず、参加状態や撮影通知を変えない。展示を見なくても本人の作品を保存できる。

## 参加しない人の体験

- 同意・写真提供を会場鑑賞の条件にしない
- 位置情報の権限は参加者にも要求しない
- カメラ機能がない環境は開始できない。カメラ拒否時は撮影・アプリ内QR読取に進めないが、会場の鑑賞はできる
- 参加しないことによる不利益や参加圧力を生じさせない
- 端末を持たない人の代理撮影や、氏名を使う参加方法は実装範囲ではない

## 表現への変換

| 入力・記録 | 本人端末 | 公開スクリーン |
|---|---|---|
| 写真 | 写真一覧、時系列の作品JPEG、振り返り3D上の写真 | 画像・画像URLを送らず、表示しない |
| 本人選択チェックポイント | 場所名・階と固定Graph上の振り返り経路 | 到着までの経路を光として再生 |
| 撮影時刻・順序 | 写真の順序・時刻 | metadataに基づく経路の順序。実移動速度の測定ではない |
| 展示会場 | 本人作品の経路終端ShibaLab | 初回到着に対応する経路終端 |

現在位置、GPS精度、他者との接近、実際の滞在時間を取得して表現する作品ではない。チェックポイント間の最短経路は本人が実際に通った道の証明ではなく、自己申告した節目を結ぶ再構成である。旧案のGPS信頼度`high/medium/low`を体験上の正確さの保証として使わない。

## 展示モード

- **展示画面`/display`:** three.jsによるキャンパス表現と到着経路再生。直接WSSでBackendの状態を受け取り、主描画機だけがFIFOを進める。Google本人確認を用い、運営資格と描画資格を分離する
- **本人作品`/log`:** ローカル写真と同梱固定Graphから、写真・振り返り3D・作品JPEGを表示する。到着前後とも利用できる
- **運営フォールバック:** 障害時の展示継続用。参加・到着・描画の成功や、会期中に実際に切り替えた実績を意味しない

旧Live展示B、リアルタイム位置群、個別写真ピン・フォトスポット、一日のGPS履歴を積み上げる集合表示は現行要件ではない。

## 体験上の原則

- 場所は本人の選択であり、測位・精密ナビゲーションではないことを隠さない
- 写真の端末保存成功と、地点metadataのサーバー受付・展示反映成功を混同しない
- 通信に失敗した参加作成、到着、停止、削除を成功表示に置き換えない
- 写真0枚でも到着登録は可能。ただし写真がない端末では本人作品JPEGは作れない
- 到着後も参加が有効なら写真を追加できるが、新しい写真は端末作品だけに残し展示用metadataへ送らない
- 任意の撮影リマインダーはGo Web Pushの30分間隔。通知拒否・非対応でも参加でき、配信時刻は保証しない
- 到着後の通知継続は、それを明示した新同意版に一致して作成されたMemoryだけに固定する。既存参加を後から継続扱いに変更しない
- 「記録を残して参加を終了」と「参加をやめる（削除）」を区別する。停止しても保存期限を短縮・延長しない
- 端末の写真は他ブラウザ・他端末へ同期されない。保存した画像は本人管理となり、アプリ内削除では取り消せない
- 日本語・英語を切り替えても参加資格・写真を作り直さない。同意の正本と参考英訳を区別する
- 写真や撮影枚数を評価・ランキング化しない

## 完成範囲と確認状況

2026年10月31日〜11月1日の会期終了は確認済みである。ここでいう完成版は実装に対応する設計であり、参加人数、公開承認、実機・機材試験、現在の受付・通知停止、期限削除・撤収完了を確認した意味ではない。再展示は未定。会期終了後も旧Live・旧クラウド写真の本人閲覧・停止・削除と期限清掃を維持する設計を変えない。
