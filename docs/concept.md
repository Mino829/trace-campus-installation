# 作品コンセプト

## 一文で表すと

「展示を見るために歩いた道が、すでに展示だった。」

## 体験

1. キャンパス入口でQRコードを読み取る
2. 利用目的を確認し、位置情報取得に同意する
3. キャンパス内を自由に歩く
4. 展示場では参加中の人々を抽象化した3DCGとして見る
5. 展示場入口で到着チェックインする
6. 自分の移動軌跡が10〜20秒に圧縮されて再生される
7. 軌跡が集合アートへ溶け込む

到着待ち画面と展示には、同じ非識別の色・記号を表示する。参加者は氏名やセッションIDを公開せずに、自分の軌跡演出を見分けられる。

## 参加しない人の体験

- 位置情報の提供は展示観覧の条件にしない
- 同意しない人も、通常表示と集合表示を鑑賞できる
- 位置取得ができない人には、QRチェックポイントまたは合成軌跡による代替参加を案内する
- 参加しないことによる不利益や、スタッフからの参加圧力を生じさせない

## 表現への変換

- 現在位置: 光、粒子、生命体
- 移動速度: 光の勢い、尾の長さ、音のテンポ
- 滞在時間: 光の大きさ、植物の成長
- 曲がった回数: 軌跡の揺れ、音色の変化
- 他者との接近: 共鳴、発光、波紋
- 過去の軌跡: 徐々に消える残光、地形の変化

## 展示モード

- 通常時: キャンパス全体を漂うカメラで参加者を表示
- 到着時: 対象者の入口から展示場までを追跡再生
- 集合表示: 一日の軌跡を重ね、キャンパスの活動を可視化

## 体験上の原則

- GPSの誤差や欠測を隠さず、光の広がりや揺らぎとして表現する
- 追跡状態、停止、削除を参加者自身が確認・操作できる
- 軌跡が短い、通信が切れた、演出が混雑した場合でも、参加者を失敗扱いにしない
- 色だけに依存せず、形、記号、動きを併用する
- 強い点滅や過大な音を避け、必要な注意と代替導線を会場入口に示す
