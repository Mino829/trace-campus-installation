# TRACE 企画概要

## 企画要約

TRACEは、展示場へ向かう参加者が残した写真と、その写真の間を歩いた時間を作品化する、キャンパス回遊型のインタラクティブ・インスタレーションである。参加者は任意で写真と位置情報の利用に同意し、写真を記憶の節目、写真撮影時GPSを推定経路のアンカーとして、展示空間の光、粒子、色、音へ変換する。撮影地点は量子化した短期ピンとして3D Mapへ現れ、3件以上集まった場所はフォトスポットになる。

本企画の中心価値は「展示を見る前に目を留め、写真に残した瞬間と、その間の移動も展示体験だった」と参加者が発見することにある。正確な人物追跡や移動分析を目的とせず、位置の不確実さや記憶の空白も含めて表現へ変換する。

希望者向けのリアルタイム位置展示は写真体験と別同意・別セッションとし、通信できる最新位置だけを短時間表示する。到着後は停止または追加同意による会場内展示を選べ、通常GPS履歴は保存・再送しない。

## 背景と機会

- キャンパス内の移動は通常、目的地へ着くための空白時間として扱われる
- 複数人の移動を重ねることで、建物ではなく人の活動からキャンパス像を描ける
- 写真を撮る行為によって、参加者自身がキャンパスで残したい瞬間を選べる
- 個人を特定しない参加設計を、作品テーマとシステム設計の両方へ組み込める
- 展示場外から体験が始まるため、キャンパス全体を作品空間として扱える

## 目的

1. 参加者が自分の写真、歩行、展示表現のつながりを理解できること
2. 他者の存在を個人特定できない抽象表現として感じられること
3. 写真と位置情報を扱う作品を、安全かつ任意参加で運用できること
4. 通信やGPSが不安定でも、展示全体が停止しないこと

## 対象者

公開前に大学と確定する。MVPの暫定対象は次のとおりとする。

- 主対象: 自分のスマートフォンを使用できる学生、教職員、来場者
- 観覧のみ: 位置情報を提供しない来場者
- 要個別判断: 未成年者、端末を持たない来場者、日本語・英語以外を必要とする来場者

同意しない人や位置情報を利用できない人も、展示の観覧と代替体験を利用できるようにする。

## 提供価値

### 参加者

- 歩いた経路が短い演出として返ってくる
- 自分が撮った写真を時系列の思い出としてスマートフォンで見返せる
- 同じ時間を歩いた他者との共在を感じられる
- 追跡状態、停止、削除を自分で制御できる

### 大学・会場

- キャンパス空間を活用した体験型展示になる
- アート、情報技術、プライバシー設計を横断する実践例になる
- 障害時も自律表現へ切り替わり、公開を継続できる

## 成功指標

以下は実地試験前の暫定値であり、展示責任者の承認後に確定する。

| 指標 | 暫定目標 | 測定方法 |
|---|---:|---|
| 同意後に有効位置を1点以上取得できた割合 | 95%以上 | セッション集計 |
| 写真を1枚以上残した参加者の割合 | 80%以上 | PhotoMoment集計 |
| 写真保存の正常完了率 | 99%以上 | アップロード・保存結果 |
| 参加開始から到着まで完了した割合 | 70%以上 | 匿名イベント集計 |
| 到着演出の正常完了率 | 95%以上 | ArrivalEvent集計 |
| 到着から演出開始までの待ち時間 | p95で30秒以内 | サーバー時刻 |
| 有効位置受信から展示反映まで | p95で2秒以内 | 受信・描画計測 |
| 公開時間中のリアルタイム展示稼働率 | 99%以上 | 運営ログ |
| フォールバック切替 | 判断後1分以内 | リハーサル計測 |
| 重大な個人情報・安全事故 | 0件 | インシデント記録 |

参加率や完了率を評価する場合も、個人や移動経路を分析する用途へ拡張しない。

## スコープ外

- 正確な屋内測位、測量、ナビゲーション
- 氏名、学籍番号、メールアドレスとの紐付け
- 個人別の行動分析、出席確認、混雑監視
- 常時バックグラウンド追跡を目的とするネイティブアプリ
- 展示目的を越えた研究・広告・広報への二次利用
- 顔認識、カメラ映像、Bluetooth端末識別子の収集
- 写真原画像の公開スクリーン表示、友人間共有、公開SNS投稿
- 写真からの人物・文字・物体分析。ただし端末内のEXIF除去や安全補助処理を除く

## 公開判断の前提

次の条件が一つでも未達の場合は、リアルタイム位置を使わず合成データ展示へ切り替える。

- 大学の施設・ネットワーク・個人情報に関する必要な承認が完了している
- 保存期間、同意文、問い合わせ先、削除方法が確定している
- 対象端末で位置取得と停止が受け入れ基準を満たしている
- 写真の非公開保存、EXIF除去、本人閲覧、写真単位・期限削除が受け入れ基準を満たしている
- 主要導線のキャンパス経路グラフが現地確認され、誤経路を高信頼度で表示しない
- 写真ピンの量子化・TTL・3件閾値・削除減算と、少人数時の保護モードが試験済みである
- 座標変換・CampusGraph・3D Mapの互換版が確定し、不一致拒否とロールバックを試験済みである
- 最大負荷、複数到着、通信断、描画停止の試験に合格している
- 当日の責任者、連絡網、起動・終了・障害手順が確定している
