# TRACE 企画概要（完成版）

更新日: 2026-11-06

## 企画要約

TRACEは、学園祭で参加者が写真に残した瞬間と、自分で選んだ撮影場所を、キャンパスの光の経路として振り返るインタラクティブ作品である。写真は参加者のスマートフォン内だけに保存する。写真ごとに選ぶチェックポイントと撮影時刻などのメタデータだけをGo Backendへ送り、固定のCampusGraph上で経路を再構成する。新しいGPSの取得・送信、リアルタイム位置追跡、写真のクラウドアップロードは行わない。

作品は二つの鑑賞先を持つ。本人端末では到着前から「作品を見る」で写真・振り返り3D・写真を一枚にまとめたJPEGを確認し、本人操作で保存できる。展示では、会場スクリーンの有効なQRを読んだ参加者の経路を、three.jsの`/display`で順番に再生する。本人の写真画像を公開スクリーンへ送らない。

本書は完成時点のコードに合わせた設計記録であり、実環境の稼働、大学・運営の承認、受入試験合格、撤収・削除完了を宣言するものではない。

## 背景と機会

- 展示会場へ向かう途中も、参加者が自分の目で選ぶ体験として扱う
- 写真の内容を解析・評価するのではなく、残した瞬間の順序と選んだ場所から作品をつくる
- GPS精度に依存せず、建物・階・チェックポイントを本人が選んで場所を記録する
- 写真をサーバーへ渡さず、本人端末で思い出を持ち帰れる形にする

## 目的

1. 写真と選んだ場所、その間を結ぶ光の経路のつながりが理解できること
2. 実際に歩いた道の測定結果ではなく、自己申告地点を結ぶ作品として鑑賞できること
3. 参加・任意通知・参加終了・削除を区別し、本人が操作できること
4. 通信失敗を参加成功・到着成功・削除成功として扱わないこと
5. 公開展示と本人の写真閲覧を分離すること

## 対象者

会期は2026年10月31日〜11月1日で、終了したことはユーザー確認済み。芝浦工業大学豊洲キャンパス教室棟3F301、両日10:00〜18:00は設計記録として残す。現在の現地案内や常設窓口を意味しない。再展示は未定である。

- 体験参加: 対応ブラウザで説明を読み、Memory参加へ同意する人
- 観覧のみ: 参加せずに会場の作品を見る人。同意・写真提供は観覧の条件にしない
- 端末の条件: カメラ機能を利用できるブラウザ。カメラ許可は初回利用時に求める。位置権限は不要
- 主な案内対象: iOS 16.4以上、Android版Chrome 111以上。既知の旧版・アプリ内ブラウザ・カメラ機能のない環境は開始前に案内する。対応判定は全端末の動作保証ではない

日本語・英語の画面切替を備える。同意はBackendが配信する日本語本文を正本とし、対応する版に限って参考英訳を併記する。その他の言語、端末を持たない人の撮影参加、未成年者等への個別運用が実施されたかは未確認である。

## 提供価値

### 参加者

- 撮った写真を同じ端末・ブラウザで見返せる
- 自分で選んだ場所を、固定Graph上の経路として振り返れる
- 展示に到着する前でも作品を見てJPEGと各写真を保存でき、ホームへ戻って撮影を続けられる
- 初回到着と、再生完了後に新しいQRを読む本人再視聴を選べる
- 記録を残した参加終了と、写真・参加記録の削除を使い分けられる

### 大学・会場

- キャンパスの建物・階・通路を活用した参加型作品になる
- 写真を公開せず、チェックポイント間の経路を公開表現へ変換できる
- 認証した運営者による受付・通知停止、単一主描画機のキュー運用、フォールバックのコードを備える

## 成功指標

完成版で確認する対象は、参加作成、端末内写真保存、メタデータ送信、到着・再視聴、本人作品保存、停止・削除の整合である。各操作の成功と、実際に写真アプリへ保存したこと・実機通知が届いたこと・現地投影できたことを同一視しない。

旧案の「GPS取得率」「写真アップロード成功率」「有効位置から2秒以内の反映」は現行機能の指標ではない。1日100人の希望・50人の予測は旧計画値で、実参加数ではない。参加人数、完了率、待ち時間分布、稼働率、事故件数等の会期実績は未確認であり、達成値を記載しない。

Frontend READMEには会期中の配備と仮想カメラを用いた実UI確認の過去記録がある。これは今回の文書改訂で実施した検証でも、実スマホ・投影機材・実Push・正式受入の合格証明でもない。

## スコープ外

- 新規GPS取得・送信、リアルタイム位置展示、屋内測位、精密ナビゲーション
- 新規写真のGCS保存、写真ピン・フォトスポット、写真色のサーバー解析
- 自己申告地点から実歩行・滞在時間・移動速度を断定すること
- 氏名・学籍番号等を用いる参加者アカウント、行動分析、出席確認、ランキング
- 写真原画像の公開展示、アプリ内の友人共有・公開SNS投稿、自動動画生成
- 他端末への写真同期や、ブラウザデータ消去後の画像復旧

本人が開始するOS共有シート・ダウンロードは作品の持ち帰りであり、サーバーが写真を公開配信する機能ではない。

## 公開判断の前提

コードの存在や本書の改訂は公開承認を変更しない。新規受付・metadata・到着・描画・Pushにはそれぞれ設定と承認が必要である。未承認の既定同意草案を公開用として採用しない。再展示する場合も、現在の受付・通知状態、同意文・保持期間・問い合わせ先、対象端末と機材、公開経路、運営体制を確認する必要がある。

会期終了だけを理由に、停止・期限清掃・全データ削除・クラウド課金停止が実施済みとはしない。既存の本人閲覧・削除期限を維持し、旧Live・旧GCS写真の本人操作と清掃に必要な機能を先に撤去しない。Backend清掃で端末内写真は消えない。

## 旧案からの変更

| 旧案 | 完成版 |
|---|---|
| GPSで現在位置を追跡し、写真GPSから経路を推定 | 新規GPSなし。本人選択チェックポイントと固定Graph |
| 写真を非公開GCSへ新規保存 | 新規写真は端末IndexedDBのみ。Goはmetadataのみ |
| Live展示B、写真ピン、3件以上のフォトスポット | 新規利用・表示を廃止。到着経路再生と本人作品に整理 |
| 到着後だけ写真ストーリーを閲覧 | 到着前から作品閲覧・JPEG保存が可能 |
| 15分または30分通知 | 任意のGo Web Push、30分のみ |
