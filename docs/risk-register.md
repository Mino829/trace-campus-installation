# リスク台帳

> 2026-10-26改訂（#23）: GPS（位置情報）不使用・写真地点（チェックポイント）自己申告仕様へ改訂。位置由来のリスクはIDを保持したまま廃止記録とし、新構成のリスクを追加した。

## 評価方法

- 発生確率: 低 / 中 / 高
- 影響: 低 / 中 / 高 / 重大
- 状態: 未対応 / 対応中 / 受容 / 解消

確率または影響が「高」以上の項目は、責任者と期限を必ず設定する。

## リスクレビュー

- Phase終了時と本番2週間前から毎週見直す
- 発生確率、影響、対策、責任者、期限を更新する
- 重大リスクが未対応なら実データを使う公開を承認しない
- 発生した障害は運用メモだけで終わらせず、該当リスクと試験へ反映する
