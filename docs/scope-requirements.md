# スコープ・要件定義（完成版）

更新日: 2026-11-06

## 文書の使い方

本書はFrontend `be94bd2`・Backend `6b87961`の完成コードを基準に、現行機能と確認すべき契約を整理する。旧GPS中心の要件を現在のMustとして引き継がない。妥当なIDは保持し、意味を変更・廃止したIDは末尾に記録する。

- **Must:** 現行機能の必須契約。公開承認済み・実機試験合格という意味ではない
- **Should:** 利用環境に依存する提供目標。非対応・失敗時の案内も必要
- 表の「確認観点」は受け入れ時に確認する内容であり、本改訂で試験を実施した結果ではない
- 会期2026年10月31日〜11月1日の終了は確認済み。現在の受付・通知・クラウド停止、削除完了、正式承認、実機試験、参加人数は未確認。再展示は未定

## 前提と暫定値

旧見出しを維持するが、下表は旧計画の暫定値ではなく**コード上の値・境界と未確認事項**を示す。

| 項目 | 完成仕様・コード上の値 | 留意点 |
|---|---|---|
| 新規参加 | Memoryのみ、`/log`でサーバー作成成功後に開始 | 受付フラグと承認が必要。未承認草案は公開不可 |
| 新規GPS・Live | 取得・送信なし。Live新規作成・位置書込み・会場内継続停止 | 旧本人状態・停止・削除と期限清掃は維持 |
| 新規写真 | 端末IndexedDBのみ、JPEG長辺1280px以下・品質0.8 | Goへ画像を送らない |
| 写真件数 | Backend metadata保持中12件まで。Frontendは公開設定の上限を利用 | 到着後写真は端末作品のみ |
| 写真metadata | `clientPhotoId`、`checkpointId`、`capturedAt` | 座標・画像・URL・サイズ等の追加フィールドを拒否 |
| 経路 | 自己申告チェックポイントと固定CampusGraph | 実歩行の測定・精密ナビではない |
| 初回到着 | 有効な投影QR、写真0枚でも可 | 待機最大50件、playingは別に最大1件 |
| 再視聴 | `completed`後の新しいQRを読む本人操作のみ | FIFO末尾。初回到着・期限を変更しない |
| 本人作品 | 到着前から表示、写真0枚では生成不可 | Goの到着・metadata送信完了に依存しない |
| 通知 | 任意のGo Web Push、30分のみ | 到着後継続は新同意版に固定した新規Memoryだけ |
| 言語 | 日本語・英語UI | 同意は日本語正本、対応版の参考英訳 |
| 期限 | 各Memoryの`expiresAt`・`deleteAfter`を使用 | 会期終了・停止だけで変更しない |
| 本番構成 | CloudflareサイトWorkerの`/api/backend`・`/api/operator`、Go、PostgreSQL、直接描画WSS | 旧loopbackブローカーはリハーサル用。現在の実配備状態は別確認 |
| Graph版 | `toyosu-graph-2026-10-29.1.draft` | Sessionに固定。版名のdraftは実装値で、承認済みを意味しない |
| その他の空間版 | `toyosu-2026-08-28.1` / `toyosu-3dmap-2026-10-30` | Graph・描画の互換を確認 |

最大50はキューの待機上限であり、同時追跡数・実参加数・検証済み処理性能ではない。再生を一律15秒、待ち時間p95 30秒、8時間無停止等とする旧計画値の達成実績は、本改訂の参照資料では確認できない。

## 対象範囲

### 対象

- `/log`の説明・同意・Memory作成、ブラウザ条件案内、日本語・英語切替
- 写真確認・チェックポイント選択・端末内JPEG保存、本人作品とJPEG持ち帰り
- `/v2`metadata登録・本人取得・削除と固定Graphの経路
- 投影QRによる初回到着、完了後新QRの本人再視聴、FIFO、単一主描画機lease
- three.jsの`/display`、Google本人確認、運営credentialとdisplayTokenの分離、直接WSS
- 任意の30分撮影通知、通知解除、参加停止と本人削除
- 旧Live・旧クラウド写真の本人権利、期限清掃、運営の受付・通知停止とフォールバック

### 対象外

- 新規GPS取得・送信、位置履歴、現在位置群の展示、屋内測位
- 新規GCS画像アップロード、写真ピン・フォトスポット、GPS精度による経路信頼度推定
- 参加者の氏名・メールを使うアカウント、ランキング、行動分析、出席確認
- 写真のサーバー公開共有・SNS投稿、自動Vlog、人物・文字・物体解析
- 写真の端末間同期、ブラウザ消去・端末紛失からの画像復旧
- カメラ機能なしの撮影参加、同じ人の複数参加防止、専用ネイティブアプリ

会場の観覧は同意なしで可能。本人が開始する共有シート・ダウンロードは作品持ち帰りであり、アプリの公開写真配信ではない。

| FR-030 | Should | 本人作品JPEGと各写真を端末へ保存できる | iOS共有シート・その他ダウンロード、非対応は長押し案内。取消・受渡しと実保存を区別 |
| FR-034 | Must | 任意のGo Web Pushを30分間隔で提供 | 別の明示操作・通知許可が必要。到着後継続は新同意版に固定した新規Memoryのみ。作品閲覧で停止しない |
| FR-035 | Must | Session・写真・Graph・描画の空間版を固定・照合 | 3つの版違いを拒否。旧写真を現在の同名IDの座標へ読み替えない |
| FR-037 | Must | 完了後の本人操作と新しいQRでのみ再視聴を申し込む | `/arrival/replay`はFIFO末尾、新公開再生ID。初回到着・期限・写真・通知方針を変えない |
| FR-038 | Must | 待機中・再生中のQR再読取は現状態へ合流 | 二重予約・割込みなし。スキップ・停止・期限後は本人再視聴不可 |
| FR-039 | Must | 到着後の追加写真は本人端末の作品だけに残す | 新しいmetadataを送らず、到着済み展示経路とローカル作品が異なる場合を隠さない |

## 変更管理

本改訂は完成コードに設計を合わせた文書変更であり、実装・公開承認・同意・保持期限・クラウド設定を変更しない。再公開やデータ用途変更では、変更理由、影響ID、同意版と本文、期限、試験・移行範囲、承認主体を記録する。未mergeの設計判断は履歴とし、承認・配備済みと断言しない。
